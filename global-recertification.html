My role

I owned it from problem definition to the last retest

That covered the learning design, content, exam, platform build, translation, rollout rules, results pipeline, and fixes after launch. I worked with the standards committee, regional leaders and trainers, and marketing, and ran operations until the completion window closed.

The problem

A substantial revision, a certified population, a hard deadline

The new release rewrote much of the standard. It added a new management framework, a new way to classify who performs work, metrics chosen by intent instead of fixed lists, and a new hierarchy of core terms.

Everyone certified on the old release, both internal consultants and clients worldwide, had to get current or lose accreditation. The only existing route was a multi-day class.

Risks

  • Accreditation lapsing across a global population at a fixed deadline
  • Changes spread across the whole standard, so a summary wouldn't be enough to apply them

 

  • Multiple languages, with very different regional training capacity
  • A badly translated or inconsistent exam would damage the standard's credibility
Process

Start from what leaders need to do

A certified leader needs to place work in the right phase of the new framework, classify a performer correctly, and choose metrics by intent. Reciting the changes doesn't help with any of that.

Define the smallest set of new behaviors

I asked the standards committee and regional leaders what a certified leader now has to do differently.

Design for the delta only

Assumed fluency in the old release and skipped the basics, which kept it under two hours.

Pilot internally first

Consultants across regions took the full training and exam over two weeks before any client saw it.

Track every piece of feedback

I logged every SME and pilot comment against its module or exam item and tracked each to a fix. That surfaced 25 distinct issues.

Settle the rules before launch

I wrote the eligibility, deadline, exception, retest, and escalation rules alongside the training.

The solution

Teach only what changed, then test it with situations

Learning path

  • Modules built around the four major changes, plus significant and minor changes
  • Short topic videos and knowledge checks inside each module
  • A quick reference companion for the new framework and terms

Exam

  • 25 scenario-based questions, 90% to pass, open book, resumable
  • Questions about situations, such as “which phase does this activity belong to?”
  • One immediate, non-punitive retest before any class is required

What the data changed

Assessment data as design feedback

One category scored 70%

I treated it as my design problem

Everything else scored 94 to 100%, so I rewrote those items and revised the module.

The time estimate was wrong

Corrected so people could plan

Pilot data showed it was too low, especially for non-native English speakers, so I updated the communications.

Translation issues showed up in scores

Spotted in the data before anyone complained

Comparing each question across languages showed which items didn't translate well, and I reworked them with the regional team.

A platform setting misbehaved

Fixed quickly and in the open

An attempt limit didn't work as labeled. I caught it, corrected the affected records, and tightened access without penalizing anyone.

The organization now has a recertification model it can reuse for the next release, so certified professionals won't need to sit a multi-day class again.
